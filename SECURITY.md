# Sicherheitsrichtlinie (Security Policy) 🏮🛡️

Sicherheit hat bei Koreki oberste Priorität. Wir schätzen die Arbeit von Sicherheitsforschern, die uns helfen, die Plattform für Lehrkräfte und Schulen sicher zu halten.

## 🏛️ Unterstützte Versionen

Derzeit werden folgende Versionen mit Sicherheitsupdates unterstützt:

| Version | Unterstützt |
| :--- | :--- |
| 0.9.x (aktuell) | ✅ Ja |
| < 0.9.0 | ❌ Nein |

## 🛡️ Melden einer Sicherheitslücke

Bitte melden Sie Sicherheitslücken **nicht** über öffentliche GitHub Issues. 

Um eine Sicherheitslücke diskret zu melden, senden Sie bitte eine E-Mail an:

**info@koreki.org**

### Was wir von Ihnen benötigen:
- Eine detaillierte Beschreibung der Schwachstelle.
- Schritte zur Reproduktion (PoC).
- Mögliche Auswirkungen auf Nutzerdaten oder die Systemintegrität.

### Unser Versprechen:
- Wir bestätigen den Eingang Ihrer Meldung innerhalb von **48 Stunden**.
- Wir halten Sie über den Fortschritt der Behebung auf dem Laufenden.
- Wir bitten Sie um eine angemessene Frist zur Behebung ("Responsible Disclosure"), bevor Informationen öffentlich gemacht werden.

## 🏛️ Industrial Security Standard
Koreki folgt dem **Industrial Defense Standard** (9 Säulen). Details zur Architektur finden Sie in unserer [Dokumentation](docs/technical/architecture.md).

Vielen Dank, dass Sie helfen, Koreki sicher zu machen!
